## Perfil Profesional

**Ubicación:** Michoacán, México &nbsp;&nbsp;|&nbsp;&nbsp; **Estatus:** Último Semestre &nbsp;&nbsp;|&nbsp;&nbsp; **Disponibilidad:** Búsqueda Activa (Prácticas / Junior)

Estudiante de Ingeniería Informática enfocado en el **desarrollo Backend, la arquitectura de software y la gestión de bases de datos relacionales**. Especializado en la construcción de APIs RESTful modulares, código limpio y tipado estricto, aplicando principios SOLID para asegurar mantenibilidad y escalabilidad. Cuento con bases sólidas en entornos Linux, control de versiones colaborativo y desarrollo web nativo sin sobrecarga de dependencias.

### Áreas de Especialización

- **Lógica de Backend:** Diseño de servicios desacoplados con separación estricta de responsabilidades (SRP), tipado estricto en PHP 8.3 y Node.js, y esquemas de autenticación segura vía JWT.
- **Modelado de Datos:** Diseño y normalización de bases de datos relacionales en MySQL, optimización de consultas y consistencia transaccional.
- **Frontend Complementario:** Construcción de interfaces responsivas y de alto rendimiento en HTML5, CSS3 y JavaScript Vanilla para una integración directa con el servidor.

## Proyectos Destacados

### EnfocaKids — Sistema de Estimulación Cognitiva y Tareas Escolares
Plataforma web modular orientada a la evaluación cognitiva infantil y soporte escolar, integrando telemetría en tiempo real, persistencia relacional y arquitectura segura.

`PHP 8.3` `MySQL` `JavaScript Vanilla` `CSS3 Nativo` `Arquitectura Modular` `JWT Auth`

- **Backend:** API REST estructurada con separación estricta de responsabilidades (SRP), tipado estricto en PHP 8.3 y aislamiento por tutor autenticado.
- **Telemetría Cognitiva:** Motor de persistencia para tiempos de reacción, precisión y cálculo de baremos psicométricos en base de datos.
- **Frontend de Alto Rendimiento:** Arquitectura 100% Vanilla Web (sin dependencias ni frameworks pesados) para garantizar tiempos de respuesta mínimos.
