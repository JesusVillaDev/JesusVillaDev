## Proyectos Destacados

### EnfocaKids — Sistema de Estimulación Cognitiva y Tareas Escolares
Plataforma web modular orientada a la evaluación cognitiva infantil y soporte escolar, integrando telemetría en tiempo real, persistencia relacional y arquitectura segura.

`PHP` `MySQL` `JavaScript Vanilla` `CSS3 Nativo` `Arquitectura Modular` `JWT Auth`

- **Backend:** API REST estructurada con separación estricta de responsabilidades (SRP), tipado estricto en PHP y aislamiento por tutor autenticado.
- **Telemetría Cognitiva:** Motor de persistencia para tiempos de reacción, precisión y cálculo de baremos psicométricos en base de datos.
- **Frontend de Alto Rendimiento:** Arquitectura 100% Vanilla Web (sin dependencias ni frameworks pesados) para garantizar tiempos de respuesta mínimos.
